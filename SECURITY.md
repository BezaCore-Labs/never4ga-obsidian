# Security

Never4gA Companion runs inside Obsidian on your machine. It talks only to the
local Never4gA service at the address in its settings, reads that service's
credential from disk at runtime without ever storing it in the vault, and
sends your notes nowhere. If you find a way around any of that, or anything
else that puts a user's notes or credentials at risk, please report it
privately.

**Report a vulnerability** through GitHub's private reporting: the *Security*
tab of this repository, then *Report a vulnerability*. Please don't open a
public issue for it.

A problem in the Never4gA service itself belongs with
[never4ga](https://github.com/BezaCore-Labs/never4ga/security), reported the
same way.

You'll get an answer within a week. This is a small project maintained by one
person, so a fix may take longer than that, and you'll be told how it's going.

Only the latest release is supported.
